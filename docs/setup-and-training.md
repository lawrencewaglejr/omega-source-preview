# Setup and training inquiries

**Contact: Lawrence Wagle Jr — Founder & Security Architect, OMEGA.**

OMEGA is an experimental source preview. We welcome inquiries about assistance
with a development or lab environment:

- A walkthrough of the fictional dashboard and guided-setup demos.
- An introduction to the software stack, source coverage and configuration guides.
- A lab setup plan and operator training on reading alerts, device observations
  and evidence exports.
- Discussion of a narrowly scoped integration or documentation task.

[Open a setup or training inquiry](https://github.com/lawrencewaglejr/omega-source-preview/issues/new?template=setup-training.yml).
GitHub Issues is the only public contact channel currently provided.

## How an inquiry works

1. Describe the outcome you want and whether you are exploring the demo,
   a disposable lab or a possible future deployment.
2. Identify the broad platform and software versions. Share only information
   suitable for a public issue.
3. Discuss feasibility, deliverables, availability and any fee before work is
   accepted. An inquiry does not book a service or establish a support contract.

Prices, scheduling and service availability are agreed case by case; no payment
is collected through an issue. No response-time commitment or ongoing monitoring
service is offered through this source-preview repository.

## Current boundaries

The project has documented validation gaps and is not a hardware-accepted
security appliance. Setup/training discussions do not imply production
readiness, a completed security assessment or guaranteed protection. Hardware
sales, managed monitoring and incident-response services are not offered here.
See the [source-preview scope](source-preview.md) and
[recorded validation results](source-preview-validation.md).

Issues are public. Do not attach passwords, keys, tokens, network captures,
operational logs, reports, private addresses/hostnames, or customer information.
Use fictional examples. If a task would require private evidence or access,
agree on a suitable private process before sharing anything; none is provided
by this public issue form.

The [Apache 2.0 source license](../LICENSE) remains available independently of
any future paid assistance. Sponsorship and service inquiries are separate.

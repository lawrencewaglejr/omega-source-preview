# Help shape OMEGA

We are looking for feedback from home-lab operators, Raspberry Pi enthusiasts,
and people exploring local network-security visibility. Start with the
[fictional demo](demo.md); no appliance access or private network data is needed.

[Share early-user feedback](https://github.com/lawrencewaglejr/omega-source-preview/issues/new?template=early-user-feedback.yml).

## Questions worth answering

1. What question about your network are you trying to answer today?
2. Which part of the fictional demo is useful, and which part is unclear?
3. Would you prefer to run the source yourself, receive a setup walkthrough,
   or consider supported hardware after validation?
4. What evidence or documentation would you need before trusting the output?
5. Which setup or training task would save you enough time to consider paying
   for assistance? It is fine to say that you only want the free source.
6. What would prevent you from trying the source preview in a disposable lab?

Comments help prioritize development. They do not reserve hardware, place an
order or commit anyone to payment. There is no hardware preorder or validated
appliance release in this repository.

## A useful first conversation

A short conversation can focus on the person's current workflow, one problem
they care about, what the demo communicates, and one next experiment. Ask about
their experience before pitching features. Record only feedback they agree to
share; summarize findings without identifying their network or customers.

Gather several independent responses before investing in appliance inventory
or promising a support offering. Distinguish interest in a screenshot from a
willingness to try the software or agree to a defined paid task.

## Keep feedback suitable for public GitHub

Issues are public. Use fictional examples and broad platform descriptions.
Do not include credentials, private hostnames/addresses, logs, reports, captures,
or information about other people. For setup/training inquiries, use the
[separate inquiry form](setup-and-training.md).

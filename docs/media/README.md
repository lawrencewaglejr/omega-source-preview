# Demo media provenance

The PNG screenshots and `omega-demo.mp4` were captured on 2026-11-14 from a
clean export of public source commit
`548141cdf4fed31a06384526fe9f5bc7c739b50d`.

The dashboard ran with `--demo`; the setup server ran with `--demo` separately.
Both servers and a fresh headless browser ran inside a disposable namespace
with loopback networking and no route to the appliance or household network.
No personal browser profile, real sensor data, credentials, operational logs,
or private deployment configuration was available to the capture.

The addresses, device names, alerts and pairing code shown are fictional demo
fixtures supplied by the source. The code `OMEGA-PREVIEW` is public sample data,
not an appliance pairing secret. The capture verified demo mode and disabled
AI, with no browser page errors or unexpected requests.

Screenshots are unaltered browser captures at 1440 × 960. The silent MP4 shows
actual dashboard interactions, encoded as H.264, with explanatory captions
added across the bottom. It is approximately 47 seconds long. Captions do not
represent additional product capabilities.

These materials illustrate an experimental interface, not live collection,
AI inference, installed host protection, hardware acceptance or a completed
security assessment. They are OMEGA project materials under the repository's
[Apache 2.0 license](../../LICENSE).

READ-ONLY ACCESS

Give this appliance its own connection

  1. Create the appliance’s SSH identity, then copy its public key.
  2. On the manager, install a dedicated reader account restricted to exporting Wazuh JSON logs. Give it read access to alerts and archives; do not grant shell or administrator access.
  3. Obtain the manager’s SSH host public key through its console or another trusted channel, then paste it below. Confirm it belongs to your manager before connecting.

Manager administrator instructions

Follow the OMEGA manager setup guide to create a dedicated restricted reader account, install this appliance’s public key, and grant access to JSON alerts and archives. These changes happen on the manager and require its administrator.

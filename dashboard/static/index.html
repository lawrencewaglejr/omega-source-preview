A hostname is a clue. A label makes it yours.

Network hostnames are shown when Pi-hole, DHCP records, or an authorized network scan provide one. Name sources and scan times help you see how each detail was found. Names and types such as Laptop or Tablet come from your device labels; OMEGA does not guess them from an address. Unknown names remain visible for review.

Discovery checks its configured Pi-hole network database or DHCP lease file every 10 seconds. Devices your source has not observed may be missing, including devices on other networks. Private or changing MAC addresses can appear as new devices.

About OMEGA

OMEGA is a Raspberry Pi-based network security appliance built to make home network activity visible, understandable, and actionable. It brings Suricata network activity, Wazuh endpoint events, Pi-hole DNS observations, device context, and local AI explanations into one place.

BUILDING WHAT COMES NEXT

More control, with honest boundaries

Optional adult-site filtering and opt-in message-content review can be saved as setup preferences. Filtering enforcement, family profiles, schedules, and supported messaging connections are still in development.

No messaging accounts are connected. Saving a preference does not authorize access or collect messages. Message review will require a supported integration and each owner’s consent; coverage of every messaging app is not promised.
